## 硬件前置条件

使用 `ce up --live` 前，需要 ROS 2、WY/O6 消息包、可执行的
`<vendor-runtime>/scripts/start.sh`，以及 CAN 设备和对应权限。
CAN 初始化由启动脚本负责；Adapter 不保存 sudo 密码。真实启动失败会停止已启动的子进程并返回错误。

本次验证没有启动真实 `robot_launch`，也没有发送真实机器人动作。
